Getting Started

Quick start guide for PaisaPhile

PaisaPhile is an AI-powered trading analysis assistant that helps you analyze market patterns, trends, and indicators using advanced LLM agents.

  1. Configure your LLM providers (OpenAI, Anthropic, Gemini, or Qwen)
  2. Start a chat and ask about any market or trading pair
  3. Get detailed analysis with pattern recognition and trend analysis
